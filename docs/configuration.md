# Configuration

All configuration lives in one file, `.env`, at the repository root. `chi init` creates it from
`.env.example` with mode 600 and fills in generated values. It is in `.gitignore`; never commit it.

How it is used:

- `bin/chi` and the scripts source it (`load_env`), so every key is an environment variable for them.
- Every `docker compose` call passes it with `--env-file`, so compose files can reference any key as
  `${KEY}`.
- After pulling a newer version of the repo, run `chi init` again: it appends keys that are new in
  `.env.example` and never overwrites values you set.
- After changing a key that containers use, run `chi up` so compose recreates the affected containers.

`chi init` only fills a key when it is empty or contains `CHANGE_ME`.

## Core

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `CHI_HOSTNAME` | `chi-mini` | Machine name: macOS ComputerName/HostName/LocalHostName and the Tailscale node name. Also the restic `--host` tag. | `bootstrap macos`, `bootstrap tailscale`, `backup`, core compose |
| `TZ` | host zone, else `UTC` | Time zone for containers (e.g. `America/New_York`). Filled by `chi init` from `/etc/localtime`. | all compose files, `photos/fetch.sh` |
| `CHI_RUNTIME` | `orbstack` | Container runtime: `orbstack` or `colima`. | `bootstrap runtime` |
| `DATA_DIR` | `~/srv/data` | Root for all persistent service data. This is what gets backed up. | all stacks, `backup`, `onboard`, `serve` |

## Stacks

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `CHI_STACKS` | `"core ai media"` | Space-separated stack names (directories under `stacks/`) that commands act on when you name none. | `up/down/restart/ps`, `update`, `serve`, `backup`, `schedule`, `doctor`, `bootstrap ollama` |

Run `chi stacks` to list available stacks; enabled ones are marked with `*`.

## Tailscale and network

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `BIND_ADDR` | `127.0.0.1` | Host address container ports bind to. `127.0.0.1`: only `tailscale serve` can reach them (recommended). `0.0.0.0`: any LAN device can use `http://<ip>:<port>`. | all compose files except `public` |
| `TS_FQDN` | (empty) | The machine's full tailnet DNS name, e.g. `chi-mini.your-tailnet.ts.net`. Filled by `chi init` once Tailscale is logged in. Used in service URLs and callbacks. | `serve`, `onboard`, `doctor`, compose files, `kuma-seed.sh` |

If `TS_FQDN` changes, run `chi up` so containers pick up the new name. `chi doctor` flags containers still
using `localhost`.

## Alerts

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `NTFY_TOPIC` | `chi-<20 random chars>` | ntfy topic for push alerts. On the public ntfy.sh server the topic name works like a password. | `scripts/kuma-seed.sh`, `doctor` |
| `HC_PING_URL` | (empty) | healthchecks.io (or compatible) ping URL. When set, a launchd job pings it every 5 minutes. | `schedule`, `doctor` |

Optional, not in `.env.example`: `NTFY_SERVER` (default `https://ntfy.sh`) for a self-hosted ntfy server,
read by `scripts/kuma-seed.sh`.

## Backup (restic)

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `RESTIC_REPOSITORY` | (empty) | restic repository. Empty disables backups and the daily job. Examples: `/Volumes/Backup/restic-chi`, `b2:my-bucket:chi-server`, `s3:https://<account>.r2.cloudflarestorage.com/chi-server`. | `backup`, `schedule`, `doctor` |
| `RESTIC_PASSWORD_FILE` | `~/.config/chi/restic-password` | File holding the repository password. Generated by `chi init` (mode 600). Losing it makes every backup unreadable. | `backup`, `init`, `doctor` |
| `B2_ACCOUNT_ID`, `B2_ACCOUNT_KEY` | commented out | Credentials for a Backblaze B2 repository. | restic |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` | commented out | Credentials for S3-compatible repositories (R2 etc.). | restic |
| `BACKUP_HOUR` | `4` | Hour (24h) of the daily backup; it runs at minute 17. | `schedule` |

## Public (Cloudflare Tunnel)

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `CF_TUNNEL_TOKEN` | (empty) | Token of a remotely managed Cloudflare Tunnel. Empty: `cloudflared` does not start. Treat it as a secret. | `public` stack (`pre-up.sh`), `doctor` |
| `PUBLIC_DOMAIN` | (empty) | Public hostname, e.g. `hello.example.com`. Only used for the Homepage link and by `remote-check`. | core compose, `remote-check` |

Setup steps: [public module](modules/public.md).

## Media

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `MEDIA_DIR` | `~/srv/data/media` | Media library root (`Downloads/`, `Keep/`, `Movies/`, `TV/`). Point it at an external disk for a larger library. | `media` stack, `media`, `backup` (excluded), `doctor` |
| `MEDIA_MAX_GB` | `60` | Size cap for `Downloads/`. Above it, `chi media clean` deletes the oldest files. | `media clean`, `doctor`, `onboard` |
| `MEDIA_MAX_HEIGHT` | `1080` | Maximum download resolution for `chi fetch` and subscriptions. | `fetch`, `media sub add` |
| `MEDIA_BIND_ADDR` | `0.0.0.0` | Address Jellyfin's port 8096 binds to. `0.0.0.0` lets TV boxes without Tailscale connect; `127.0.0.1` restricts it to the tailnet. | `media` stack |
| `JELLYFIN_API_KEY` | (empty) | Jellyfin API key (Dashboard -> API Keys). Required by `chi media scan` and `chi media iptv`; enables the Homepage widget. | `media`, core compose |
| `IPTV_M3U_URLS` | (empty) | Space-separated M3U playlists for live TV. Empty uses iptv-org's China playlist. | `media iptv` |

## Scrape

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `FIRECRAWL_VERSION` | (empty = `latest`) | Tag of `ghcr.io/firecrawl/firecrawl`. Set an exact build such as `2.11.616` to pin or roll back. | `scrape` stack |
| `FIRECRAWL_MODEL` | (empty) | Model for AI features (`/extract`, JSON formats): `claude-*` uses the Anthropic API, anything else an Ollama model on the host. Empty turns them off; scraping and crawling still work. | `scrape` stack |
| `ANTHROPIC_API_KEY` | (empty) | Anthropic API key, needed only when `FIRECRAWL_MODEL` is a `claude-*` model. | `scrape` stack |

## Split-routing proxy

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `CLASH_SUBSCRIPTION_URL` | `''` | Clash / Clash Meta subscription URL of your upstream proxy provider. Treat it as a password. **Wrap it in single quotes**: URLs often contain `&`. Setting it also enables the proxy checks in `chi doctor`. | `proxy`, `doctor` |
| `CLASH_CN_FILTER` | ASCII regex for mainland-China node names | Regex that selects nodes from the subscription. Use `'.*'` if every node exits where you need. Add your provider's node naming if it differs. | `proxy` |
| `CLASH_PORT` | `7890` | mihomo mixed (HTTP + SOCKS5) port. | `proxy`, `tv proxy`, `onboard` (PAC), `media` pre-up, `doctor` |

Details: [split-routing module](modules/split-routing.md).

## Dotfiles (optional)

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `DOTFILES_REPO` | (empty) | chezmoi source, e.g. `github-user` or `github-user/dotfiles`. Empty skips the step. | `bootstrap dotfiles` |
| `DOTFILES_BRANCH` | (empty) | Branch of `DOTFILES_REPO`; empty uses the default branch. | `bootstrap dotfiles` |

On first run the step backs up `.zshrc`, `.gitconfig` and similar files to
`~/.local/state/chi-dotfiles-backup/<date>/` before chezmoi applies.

## Service secrets

Generated by `chi init`. Do not fill them in by hand, and do not change them on a running system.

| Key | Default | Meaning | Used by |
|---|---|---|---|
| `OPEN_WEBUI_SECRET_KEY` | random 64 hex | Open WebUI session signing key. | `ai` stack |
| `N8N_ENCRYPTION_KEY` | random 64 hex | Encrypts every credential n8n stores. Lose it and saved credentials are gone. Backed up with `.env`. | `automation` stack |
| `CLASH_SECRET` | random 32 hex | mihomo API / dashboard secret. | `proxy` |
| `FIRECRAWL_LLM_KEY` | `sk-` + random 48 hex | Key between Firecrawl and its LiteLLM gateway; never leaves the stack's network. | `scrape` stack |
| `VAULTWARDEN_SIGNUPS_ALLOWED` | `false` | Set `true` only while creating accounts, then back to `false` and `chi up vault`. | `vault` stack |

## Other environment variables

These are not in `.env.example`. Set them in `.env` or in your shell when needed.

| Variable | Default | Meaning | Used by |
|---|---|---|---|
| `CHI_SSH_KEY_ONLY` | `0` | `1` disables SSH password login (only if `~/.ssh/authorized_keys` is non-empty). | `bootstrap macos` |
| `KUMA_PASSWORD_FILE` | (unset) | Path to a file with the Uptime Kuma password, for non-interactive seeding. | `scripts/kuma-seed.sh` |
| `CHI_TS_API_KEY_FILE` | `~/.config/chi/tailscale-api-key` | Tailscale API access token file. | `scripts/friend-ts.sh` |
| `TS_API_BASE` | `https://api.tailscale.com/api/v2` | Tailscale API base URL. | `scripts/friend-ts.sh` |
| `CHI_REMOTE_DIR` | `~/chi-server` (falls back to `~/chi-service`) | Checkout path on the server, as seen by the client. | `remote-check` |

## Files outside `.env`

| Path | Contents |
|---|---|
| `~/.config/chi/restic-password` | restic repository password (`RESTIC_PASSWORD_FILE`). |
| `~/.config/chi/tailscale-api-key` | Tailscale API token for `friend-ts.sh`. |
| `~/.config/chi/acl-backups/` | Tailnet policy backups taken before `friend-ts.sh` writes. |
| `stacks/<name>/.env` | Generated per-stack env (`media`, `public`, `photos`); never edit or commit. |
| `$(brew --prefix)/etc/mihomo/config.yaml` | Rendered mihomo config (contains the subscription URL, mode 600). |
